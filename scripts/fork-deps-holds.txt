# Fork addition: what the automatic dependency update (scripts/fork-deps-update.mjs)
# must never change, or not beyond a ceiling. One per line:
#
#   <eco> <name> <ceiling> <reason>
#
# eco: go, npm, action, image, toolchain, node, bundled, path. Ceiling: "-" never
# touched; "1" stays in major 1; "1.5" stays at or below 1.5.x. A line
#   group <eco> <name> <name>...
# names packages whose majors are only tried together. Keep a reason on every
# line; remove a hold when its reason no longer holds. Changing this file is a
# decision of the owner (or of a session the owner asked), never of the machine:
# the update's own checks refuse a change to it.
